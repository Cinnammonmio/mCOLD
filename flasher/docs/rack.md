# ผลิตทีละมาก: USB เร็ว แล้วทำที่เหลือผ่าน Wi-Fi → MQTT (ชั้นวาง)

Dock มี 6 ช่อง ถ้ากล่องอยู่ในช่องนาน 5–10 นาที (bringup, ลบชิป, flash, ทดสอบ, logtest, ตอบคำถาม)
100 เครื่องจะใช้เวลาครึ่งวัน วิธีนี้ให้กล่องอยู่ที่ Dock แค่ราว **1.5 นาที** เพื่อทำสิ่งที่ต้องใช้สายจริง ๆ
แล้วไปวางบน **ชั้นวาง** (ที่ชาร์จ USB ธรรมดา ไม่ต่อ PC) ที่เหลือทั้งหมดทำผ่าน Wi-Fi พร้อมกันหลายสิบกล่อง

```
Dock (โหมด "USB เร็ว → ชั้นวาง MQTT")         ชั้นวาง (หน้า "ชั้นวาง" ในหน้าต่าง)
  ชิป ESP32-S3 16 MB                             ขึ้น broker, IP ตรงกับเลขเครื่อง, firmware ตรง
  ลบชิป + flash firmware จริง                    อุณหภูมิ / ไฟเลี้ยงจาก status
  SN (ล็อต + เลขเครื่อง) → reboot                 ทดสอบโมดูล I2C, อุณหภูมิ, GNSS, trip log
  Wi-Fi โรงงาน + IP คงที่ + broker + OTA + ค่าตั้ง   ไฟ + เสียง: คนตอบทีละกล่องตามคิว
  เปิดโหมดโรงงาน                                 ดึง debug เก็บเป็นไฟล์
  health เร็ว → ถอด                              ส่งค่าตั้งของ site
                                                ส่งมอบ: ใส่ Wi-Fi ลูกค้า แล้วลบ Wi-Fi โรงงาน (ข้อสุดท้าย)
```

ต้องใช้ firmware ที่มีคำสั่งผ่าน MQTT ([firmware-mqtt-rpc.md](firmware-mqtt-rpc.md)) ถ้า firmware ยังไม่มี
ขั้น "เปิดโหมดโรงงาน" ที่ Dock จะไม่ผ่านพร้อมบอกให้ใช้โหมด "ทำใหม่ทั้งหมด" ไปก่อน
กล่องจะไม่ถูกปล่อยออกไปโดยไม่ได้ทดสอบ

## เตรียม (ครั้งเดียว)

1. **Wi-Fi โรงงาน** AP ที่ไม่ใช่ของลูกค้า ชื่อไม่มีช่องว่าง AP ทั่วไปรับได้ราว 30–50 เครื่อง
   ถ้าจะวางพร้อมกันมากกว่านั้นใช้ AP องค์กรหรือหลายตัวชื่อเดียวกัน
2. **IP pool** เลือกช่วงที่ DHCP ของ AP ไม่แจก เช่น วง `10.20.0.0/24` gateway `10.20.0.1`
   IP ฐาน `10.20.0.100` → เครื่อง 001 = `10.20.0.101`, เครื่อง 154 = `10.20.0.254`
   (หน้าตั้งค่าบอกว่ามีที่ให้กี่เครื่อง) เลขเครื่องเกินที่ pool รับได้ = ขั้น USB ไม่ผ่าน
3. **Broker** ใช้ broker จริงที่กล่องจะใช้หลังส่งของ (เปลี่ยน broker ผ่าน MQTT ไม่ได้)
   ใส่ login ของสถานีเองในหน้าตั้งค่า (ว่าง = ใช้ login เดียวกับกล่อง) เปลี่ยน broker แล้ว**เปิดโปรแกรมใหม่**
4. `pip install -r requirements.txt` (มี `paho-mqtt` เพิ่ม)
5. หน้าตั้งค่า (⚙): ส่วน **Wi-Fi โรงงาน + IP คงที่**, **Wi-Fi ที่ใส่ให้ทุกกล่อง** (ของลูกค้า ใส่ตอนส่งมอบ),
   **Broker**, **OTA**, **ค่าตั้งต้น**

## ใช้งาน

1. กรอกล็อต SN เลือกโหมด **USB เร็ว → ชั้นวาง MQTT** แล้วเปิด **เริ่มเองเมื่อเสียบ**
2. เสียบกล่องที่ Dock: เริ่มเอง ไม่มีคำถาม แต่ละช่องแสดง SN, MAC, FW และ **IP** ที่กล่องจะได้
3. ช่องเป็นสีเขียว → ย้ายกล่องไปวางบนชั้นวาง แล้วเสียบกล่องถัดไป
4. หน้า **ชั้นวาง**: กล่องขึ้นเป็นการ์ดเรียงตามเลขเครื่อง เริ่มเองเมื่อ online
   - คำถามขึ้นทีละกล่องด้านบน ตัวเลขใหญ่คือเลขเครื่องบนฉลาก กล่องนั้นกะพริบไฟขาวและบี๊บ
     ตอบ **ใช่ (Y)** / **ไม่ผ่าน (N)** / **ทำซ้ำ (R)** ได้จากคีย์บอร์ด
   - กดที่ตัวเลขด้านบน (ยังไม่ online / กำลังทำ / รอคน / ส่งมอบแล้ว / ไม่ผ่าน) เพื่อกรอง
   - กดการ์ดเพื่อดู log ของกล่องนั้น · ปุ่ม ▶ บนการ์ด = ทำซ้ำ
5. **ส่งมอบแล้ว** (เขียว) = กล่องออกจาก Wi-Fi โรงงานแล้ว ถอดเก็บได้
   **ไม่ผ่าน** (แดง) = ยังอยู่ใน Wi-Fi โรงงานที่ IP เดิม ส่งโต๊ะซ่อม (bringup ยังใช้ที่โต๊ะซ่อม)
6. **สรุป SN** เห็นทั้งสองขั้น (USB เร็ว + ชั้นวาง) ผ่านครบ = ผ่าน

## ข้อควรรู้

- IP ผูกกับเลขเครื่อง ไม่ใช่ล็อต: ล็อตใหม่เลขเดียวกันได้ IP เดิม สถานีจะไม่ให้ IP ที่กล่องอื่นยังถืออยู่
  (กล่องที่ยังไม่ได้ส่งมอบ) ถ้ากล่องนั้นทิ้งไปแล้ว ลบบันทึกในสรุป SN ก็ได้ IP คืน
- debug ของแต่ละกล่องอยู่ที่ `records/debug/<SN>/`
- MQTT ตอนนี้เป็น 1883 ไม่เข้ารหัสและใช้ login ร่วมกัน (PROTOCOL.md §6): รหัส Wi-Fi ลูกค้าที่ส่งตอนส่งมอบวิ่งเป็นข้อความเปิด
  ใน Wi-Fi โรงงาน ใช้ Wi-Fi โรงงานที่คนนอกเข้าไม่ได้ และกล่องรับคำสั่งเขียน/ทดสอบผ่าน MQTT เฉพาะตอนอยู่ในโหมดโรงงานเท่านั้น
- ลองดูทั้งสายโดยไม่มีบอร์ด: `mflash gui --demo` (กด "ล้าง" ที่ช่อง = ย้ายกล่องไปชั้นวาง)

## ประมาณเวลา (ต้องวัดจริงใน pilot 6–10 เครื่อง)

ขั้น USB ราว 1.5–2 นาที × Dock 6 ช่อง + เริ่มเองเมื่อเสียบ ≈ 60–90 กล่องต่อชั่วโมง (จำกัดด้วยคนเสียบ/ถอด
และ hub ของ Dock ที่แบ่ง USB 12 Mbps กันทุกช่อง) ชั้นวางทำพร้อมกัน ช่วงที่ต้องใช้คนคือดูไฟ/เสียงราว 10 วินาทีต่อกล่อง
**100 เครื่องราว 2–3 ชั่วโมง** จากเดิมราว 5–8 ชั่วโมง
