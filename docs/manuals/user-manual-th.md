# mCOLD Foam V.1 — คู่มือการใช้งาน

ฉบับร่าง 1 · ตุลาคม 2026 · firmware 0.7

## 1. เกี่ยวกับ mCOLD

mCOLD เป็นกล่องควบคุมความเย็นที่บันทึกอุณหภูมิของสินค้าตลอดการขนส่ง
ตั้งแต่เริ่ม trip จนจบ trip เครื่องจะ:

- วัดอุณหภูมิด้วย probe และบันทึกทุก 5 นาที
- แจ้ง alarm เมื่ออุณหภูมิออกนอกช่วงที่กำหนดไว้ของ trip นั้น
- เก็บข้อมูลไว้ในเครื่อง และส่งขึ้น server ผ่าน Wi-Fi เมื่อเชื่อมต่อได้
- บันทึกตำแหน่งจาก GNSS และการขยับ/สั่นของกล่อง

## 2. ส่วนประกอบ

| ส่วน | หน้าที่ |
|---|---|
| จอ e-paper | แสดงอุณหภูมิและสถานะ ภาพค้างอยู่ได้แม้ไม่มีไฟ |
| ไฟหน้า 3 ดวง | ซ้าย = สินค้า, กลาง = trip, ขวา = เครื่อง (ดูหัวข้อ 6) |
| ไฟข้างเครื่อง | สถานะการชาร์จ ติดเฉพาะตอนเสียบสาย |
| เสียง (buzzer) | ดังเมื่อเกิด alarm อุณหภูมิ |
| จุดแตะ NFC | แตะโทรศัพท์เพื่อเชื่อมต่อกับแอป |
| พอร์ต USB-C | ชาร์จแบต |
| สวิตช์เปิด/ปิด | ตัดไฟทั้งเครื่อง |
| probe อุณหภูมิ | วัดอุณหภูมิสินค้า |

## 3. เปิดและปิดเครื่อง

**เปิด:** เลื่อนสวิตช์ ไฟหน้า 3 ดวงกวาดสีขาวจากซ้ายไปขวา แล้วกะพริบเขียวพร้อมกัน
แปลว่าเครื่องพร้อมใช้งาน ถ้ากะพริบเหลือง 3 ครั้งที่ไฟขวาแทน แปลว่ามีอุปกรณ์ในเครื่องทำงานไม่ปกติ

**ปิด:** เลื่อนสวิตช์ เครื่องหยุดทำงานทั้งหมด นาฬิกาในเครื่องยังเดินต่อด้วยถ่านสำรอง
ถ้าปิดระหว่าง trip เมื่อเปิดใหม่ trip จะทำงานต่อ และบันทึกช่วงที่หายไปไว้

**ระหว่างใช้งานบนแบต** เครื่องจะหลับเกือบตลอดเวลาเพื่อประหยัดไฟ และตื่นขึ้นมาเองทุก 5 นาที
เพื่อวัดและบันทึก จอยังแสดงข้อมูลล่าสุดค้างไว้ตามปกติ

## 4. แบตเตอรี่และการชาร์จ

เสียบสาย USB-C เพื่อชาร์จ ไฟข้างเครื่องบอกสถานะ:

| ไฟข้างเครื่อง | ความหมาย |
|---|---|
| เหลือง ค่อยๆ สว่าง-หรี่ | กำลังชาร์จ |
| เขียว ค่อยๆ สว่าง-หรี่ | ชาร์จเกือบเต็ม (ตั้งแต่ 80%) |
| เขียวติดค้าง | ชาร์จเต็ม |
| เหลือง กะพริบช้า | มีไฟเข้าแต่ไม่ได้ชาร์จ |
| แดง กะพริบ | การชาร์จผิดปกติ (มีเสียงบี๊บ 1 ครั้ง) |
| ดับ | ไม่ได้เสียบสาย |

ระหว่างเสียบสาย เครื่องจะไม่หลับ และเชื่อมต่อ Wi-Fi ค้างไว้

### การป้องกันแบต

| ระดับแบต | เครื่องทำอะไร |
|---|---|
| ต่ำกว่า 15% | ไฟขวากะพริบเหลือง และบันทึก alarm แบตต่ำใน trip |
| ต่ำกว่าประมาณ 10% | ไม่ให้เริ่ม trip ใหม่ (เครื่องยังทำงาน) — ชาร์จก่อน |
| ต่ำกว่าประมาณ 5% | จอขึ้น **BATTERY EMPTY** แล้วเครื่องดับเองเพื่อป้องกันแบตเสื่อม/บวม |

เมื่อเครื่องดับเพราะแบตหมด ข้อมูลทั้งหมดยังอยู่ เสียบสาย USB-C แล้วเครื่องจะเปิดเอง
และ trip ที่ค้างอยู่จะทำงานต่อ

## 5. หน้าจอ

| ตำแหน่ง | แสดง |
|---|---|
| แถบบน | รหัสเครื่อง และเวลา (เวลาท้องถิ่น) |
| กลางจอ | อุณหภูมิล่าสุด (°C) ตัวใหญ่ |
| ใต้ตัวเลข | ต่ำสุด / สูงสุดของ trip นี้ หรือ "NO ACTIVE TRIP" เมื่อไม่มี trip |
| แถบล่าง ซ้าย | ไอคอน Wi-Fi, server, GNSS, trip |
| แถบล่าง ขวา | การชาร์จ, แบต %, พื้นที่เก็บข้อมูล % |

ไอคอน Wi-Fi, server และ GNSS ที่มีขีดทับ แปลว่ายังไม่เชื่อมต่อ หรือไม่ได้ข้อมูลล่าสุด

**สีแดงบนจอ:** ตัวเลขแดง = อุณหภูมิออกนอกช่วง · ตัวเลขแดง + กรอบแดง = alarm ·
`--` สีแดง = อ่านค่าจาก probe ไม่ได้

**การอัปเดตจอ:** จอเปลี่ยนเมื่อข้อมูลเปลี่ยน อย่างมากทุก 5 นาที แต่จะเปลี่ยนทันทีเมื่อเกิด alarm,
เริ่ม/หยุด trip หรือเสียบ/ถอดสาย การ refresh จอใช้เวลาประมาณ 2 วินาที

## 6. ไฟและเสียง

| ไฟ | รูปแบบ | ความหมาย |
|---|---|---|
| ไฟหน้าทั้ง 3 | กวาดขาว แล้วกะพริบเขียว | เปิดเครื่องแล้ว พร้อมใช้งาน |
| ไฟหน้าทั้ง 3 | กะพริบขาว 1 ครั้ง | แตะ NFC สำเร็จ |
| กลาง | กะพริบเขียว 3 ครั้ง | เริ่ม trip แล้ว |
| กลาง | กะพริบเขียวสั้นๆ ทุก 15 นาที | trip ทำงานปกติ |
| กลาง | กะพริบเขียว 1 ครั้ง | หยุด trip แล้ว |
| ซ้าย | กะพริบแดง 2 ครั้ง + บี๊บ 3 ครั้ง | alarm อุณหภูมิ |
| ซ้าย | กะพริบน้ำเงิน 1 ครั้ง | รับทราบ alarm แล้ว |
| ขวา | กะพริบเหลือง 3 ครั้ง | ปัญหาของเครื่อง เช่น probe หลุด, แบตต่ำ, นาฬิกาไม่มีเวลา |

เมื่อมีคนยกหรือขยับกล่อง เครื่องจะแสดงไฟสถานะให้เห็นสั้นๆ (จำกัดจำนวนครั้งต่อชั่วโมงเพื่อประหยัดแบต)

## 7. Trip

### เริ่ม trip

ช่วงอุณหภูมิที่ยอมรับได้ (เช่น 2–8 °C) ตั้งตอนเริ่มแต่ละ trip จึงใช้กล่องเดียวกันกับสินค้าต่างชนิดได้
เมื่อเริ่มสำเร็จ ไฟกลางกะพริบเขียว 3 ครั้ง และจอแสดงไอคอน trip

เครื่องจะไม่ให้เริ่ม trip ถ้า: มี trip อื่นทำงานอยู่, แบตต่ำเกินไป หรือพื้นที่บันทึกเต็มและไม่มีข้อมูลที่ลบได้

### ระหว่าง trip

- บันทึกอุณหภูมิทุก 5 นาที พร้อมแบต ตำแหน่ง และจำนวนครั้งที่กล่องถูกขยับ
- ถ้าเครื่องถูกปิดหรือรีเซ็ตกลางทาง trip จะทำงานต่อเมื่อเปิดใหม่ ไม่เริ่ม trip ใหม่แทน

### Alarm

| Alarm | เกิดเมื่อ | หายเมื่อ |
|---|---|---|
| อุณหภูมิสูง / ต่ำ | อุณหภูมิอยู่นอกช่วงต่อเนื่องเกินเวลาที่ตั้งไว้ (ปกติ 5 นาที) | กลับเข้าช่วงลึกกว่าขอบ 0.5 °C |
| probe | อ่านค่า probe ไม่ได้นานเกิน 1 นาที | อ่านได้อีกครั้ง |
| แบตต่ำ | แบตต่ำกว่า 15% | แบตกลับขึ้นถึง 20% |

การรับทราบ (ack) alarm หยุดเสียงและบันทึกว่ามีคนรับทราบแล้ว แต่ประวัติ alarm ยังอยู่ครบ

### หยุด trip

เมื่อหยุด ไฟกลางกะพริบเขียว 1 ครั้ง และจอแสดงสรุปของ trip นั้นประมาณ 1 ชั่วโมง

## 8. การเชื่อมต่อ

**NFC:** แตะโทรศัพท์ที่จุด NFC ไฟหน้ากะพริบขาว เครื่องจะเปิด Bluetooth ให้แอปเชื่อมต่อได้ 60 วินาที
การแตะยังใช้ยืนยันสิทธิ์ ไม่ต้องจับคู่หรือใส่รหัส

**Wi-Fi:** เครื่องจำเครือข่ายได้สูงสุด 5 เครือข่าย และเลือกตัวที่สัญญาณแรงที่สุด
เจ้าหน้าที่เป็นผู้ตั้งค่าให้ ระหว่างใช้แบต เครื่องจะเชื่อมต่อสั้นๆ ทุก 5 นาทีเพื่อส่งข้อมูลใหม่
ถ้าเชื่อมต่อไม่ได้ จะเว้นระยะนานขึ้นเพื่อประหยัดแบต ข้อมูลรอส่งอยู่ในเครื่อง ไม่หาย

**เวลา:** เครื่องตั้งเวลาเองจากอินเทอร์เน็ตหรือดาวเทียม และเดินต่อแม้ปิดเครื่อง

## 9. ข้อมูลในเครื่อง

- เก็บได้ประมาณ 268 วัน ที่การบันทึกทุก 5 นาที
- ข้อมูลถูกส่งขึ้น server และลบออกจากเครื่องเฉพาะเมื่อ server ยืนยันว่าได้รับแล้ว
- ถ้าพื้นที่เต็ม เครื่องลบ trip เก่าที่ server ยืนยันแล้วก่อน
- ข้อมูลไม่หายเมื่อไฟดับหรือแบตหมด

## 10. แก้ปัญหาเบื้องต้น

| อาการ | ทำอย่างไร |
|---|---|
| จอขึ้น BATTERY EMPTY / เครื่องไม่ติด | เสียบ USB-C ชาร์จ เครื่องจะเปิดเอง |
| เริ่ม trip ไม่ได้ | ชาร์จแบต, หยุด trip เดิมก่อน |
| ไฟขวากะพริบเหลือง | ตรวจ probe ว่าเสียบแน่น, ชาร์จแบต ถ้ายังเป็นอยู่ติดต่อเจ้าหน้าที่ |
| จอแสดง `--` สีแดง | probe หลุดหรือเสีย ตรวจการเสียบ probe |
| ไอคอน Wi-Fi มีขีดทับตลอด | อยู่นอกพื้นที่ Wi-Fi ที่ตั้งไว้ ข้อมูลยังเก็บในเครื่อง |
| ไฟข้างเครื่องกะพริบแดง | ถอดสายแล้วเสียบใหม่ ถ้ายังเป็นอยู่ติดต่อเจ้าหน้าที่ |

## ยังไม่รวมในฉบับนี้

- ขั้นตอนในแอป: เริ่ม/หยุด trip, ตั้งช่วงอุณหภูมิ, ack alarm, ดูข้อมูล (แอปยังไม่เสร็จ)
- ระยะเวลาใช้งานต่อการชาร์จ และเวลาชาร์จเต็ม (รอผลวัด)
- สเปกเครื่อง: ขนาด, น้ำหนัก, อุณหภูมิใช้งาน, การกันน้ำ, มาตรฐาน (รอข้อมูล)
- ภาพเครื่องและตำแหน่งสวิตช์ / พอร์ต / จุด NFC (รอภาพเครื่องจริง)
- จอสี 4 สี (ยังไม่ได้รับจอ), alarm การกระแทก (รอค่าเกณฑ์), เซ็นเซอร์ประตู (ปิดอยู่)
- การดึงข้อมูลผ่าน USB drive / SD card และการอัปเดต firmware (พักไว้)
- ความแม่นยำการวัดอุณหภูมิ (รอผลสอบเทียบ)
